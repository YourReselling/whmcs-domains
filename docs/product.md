# Domains

WHMCS: `yourresellingdomains` im Registrar-Verzeichnis. Registrierung/Transfer, Verfügbarkeit ohne Premium-Bestellungen, Nameserver, Basis-DNS, Auth-Code und Status-/Transfer-Synchronisierung. Keine gefälschte `RenewDomain`-Funktion: Ein expliziter API-Renew-Endpunkt fehlt. Kein Registrar-Lock-Setter, Kontakttausch oder Domain-Delete-Endpunkt. DNS ersetzt die ganze Zone; bei erweiterten, in WHMCS nicht darstellbaren Records wird das Speichern verweigert. Blesta enthält in diesem Paket Hosting-Module; Domain-Manager-Registrar-Automation wird nicht vorgetäuscht.
